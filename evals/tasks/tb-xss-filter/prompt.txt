Create /filter.py in this folder (so `filter.py` in the project root): `python3 filter.py input.html output.html` must read an HTML file and write a copy with all JavaScript removed so it can't execute: script elements, inline event handler attributes (onclick, onerror, onload, onfocus and every other on* attribute), and javascript: URLs (including ones disguised with letter case, whitespace or HTML entities). Everything else must stay exactly as it was, byte for byte: a harmless document must come out identical. Python standard library only.
